# Contributing

1. Read `AGENTS.md` and `docs/GIT_WORKFLOW.md`.
2. Branch from `main` (`feat/…`, `fix/…`), use Conventional Commits, open a PR.
3. `./scripts/verify.sh` must pass. Add tests. Keep PRs small.
4. Contributions are accepted under the MIT license.
Code of Conduct: Contributor Covenant 2.1 (add `CODE_OF_CONDUCT.md` before the repo goes public).
